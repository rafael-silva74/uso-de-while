# 🧠 Atividades de Lógica de Programação em JavaScript

Este repositório contém a resolução de cinco exercícios de lógica de programação desenvolvidos em JavaScript, utilizando estruturas de repetição (`while`), validação de dados e operações básicas.

---

## 🚀 Tecnologias utilizadas

- JavaScript
- Visual Studio Code
- Git e GitHub
- Navegador (execução via prompt/alert)
- Flowgorithm (opcional para visualização do fluxo)

---

## 📌 Exercícios desenvolvidos

### 1. Número positivo
O programa solicita que o usuário digite um número positivo. Caso ele digite um número negativo, o sistema continua pedindo até que um valor válido seja informado.

---

### 2. Média de notas
O usuário pode digitar notas de 0 a 10 indefinidamente. O programa só para quando um número negativo for digitado. Ao final, é exibida a média das notas.

---

### 3. Soma de compras
O programa solicita valores de compras e realiza a soma total. A entrada continua até que o usuário digite 0, momento em que o total da compra é exibido.

---

### 4. Nome e sobrenome
O programa solicita nome e sobrenome separadamente. Se algum dos campos estiver vazio, o sistema pede novamente até que ambos sejam preenchidos corretamente.

---

### 5. Sistema de saque
O programa simula um saldo inicial. O usuário tenta realizar saques e o sistema verifica se há saldo suficiente. Caso não haja, solicita um novo valor até que o saque seja possível. O processo continua até o saldo chegar a 0 ou negativo.
